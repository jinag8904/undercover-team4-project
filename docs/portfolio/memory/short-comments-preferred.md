주석을 짧게 쓰는 것을 선호한다. 새로 쓰는 주석은 물론이고, 코드를 옮길 때 딸려 오는 기존 주석도
길면 줄여 달라고 요청한다.

**Why:** 2026-08-08 #503 7번(NpcController 부품 분리) 작업 중 두 번 지적했다 —
"주석이 너무 긴 것 같아요", "주석 왤케 많아여? 좀 줄일 수 없음?". 이 저장소는 주석 비율이
20~45%로 원래 높은 편이라(옮겨온 파일도 그 비율을 그대로 유지한다) 그냥 두면 계속 걸린다.

**How to apply:** 강도는 "중간" — 설계 근거·실측치·이슈 번호(#123)는 남기고 **서술만 압축**한다.
XML 문서는 요약 한두 줄 + 꼭 필요한 근거만. 자명한 것과 중복 설명은 삭제.
단 리팩토링에서 주석을 손대면 "순수 이동"이 아니게 되므로, 유실 검사는 눈이 아니라 서명 목록
대조로 할 것. 커밋을 가를지 함께 담을지는 물어보되 사용자는 함께 담는 쪽을 골랐다.
