# 별점 1점 경찰서 (One-Star Precinct)

> **오합지졸 우당탕탕 빌런 검거 대작전**
> 치안이 무너진 사이버펑크 도시에서, 예산 부족에 시달리는 "별점 1점짜리 경찰서"의 로봇 경찰이 되어
> **본부(관제)** 와 **현장(수사)** 으로 나뉘어 무전으로 소통하며 지명수배범을 검거하는 **3~6인 비대칭 협동 추리 게임**.

| 항목 | 내용 |
|---|---|
| 장르 | 비대칭 협동 추리 / 파티 게임 |
| 인원 | 3~6인 온라인 협동 (세션 최대 6인) |
| 플랫폼 | PC (Windows) |
| 엔진 | Unity `6000.3.15f1` (URP) |
| 네트워크 | Netcode for GameObjects + Unity Gaming Services (Relay · Lobby · Vivox) |
| 개발 기간 | 2026-07-08 ~ 2026-09-07 (약 9주) |
| 팀 구성 | 4인 (클라이언트 프로그래밍) |
| 규모 | 런타임 스크립트 약 540개 · 플레이 맵 2종 · 시민 NPC 80~100명/라운드 |
| 레퍼런스 | *Papers, Please* (수배 대조) · *Lethal Company* (음성 협동, 실수가 웃음이 되는 플레이) |

## 어떤 게임인가

한 라운드는 **10분**. 팀은 그 안에 **목표 금액(할당량)** 을 채워야 하고, 라운드가 지날수록 목표는 올라간다.
돈이 되는 것은 **수배범 검거**뿐인데, 도시를 걸어 다니는 **시민 80~100명** 중 누가 수배범인지는 아무도 모른다.

수배범은 라운드 시작에 최대 5~6명이 정해지지만 **처음 공개되는 건 2명뿐**이다.
나머지는 본부로 걸려 오는 **제보 전화**가 울릴 때마다 한 명씩 풀린다 — 받으면 그 시점을 앞당긴다.

### 본부와 현장 — 비대칭이 게임의 뼈대

본부는 특정 인물의 고정 역할이 아니라 **맵 위의 하나의 "장소"** 다. 누구든 본부에 들어가면 본부가 되고, 나가면 현장이 된다.
본부 기능은 전부 **그 자리에 있는 물리 콘솔**(CCTV 키패드·모니터·단말)로만 조작되기 때문에,
본부에 사람을 둘수록 현장 인원이 줄어드는 **트레이드오프**가 매 순간 판단을 강요한다.

| | 본부 (관제) | 현장 (수사) |
|---|---|---|
| 보는 것 | CCTV 다중 채널(적외선 전환 포함), 미니맵 — **맵 전체의 위치** | 실제 도시, 시민의 겉모습 — **눈앞의 한 명** |
| 하는 일 | 추격 지휘 · 원격 문 개방 · 유치장 감시 · 해킹 복구 · 사이렌 | 관찰 · 스캔 · 추격 · 검거 · 연행 |
| 자리를 비우면 | 잠긴 문·해킹·탈옥에 아무도 대응하지 못함 | 아무도 잡으러 가지 못함 |

**수배 몽타주와 이름은 Tab 상황판으로 전원이 같이 본다.** 나뉘는 것은 그다음이다 —
**스캔 결과는 스캔한 본인 화면에만** 뜨고, **누가 어디로 달아났는지는 본부 화면에만** 보인다.
"파란 모자, 골목으로 튀었어" 같은 말이 늦거나 어긋나는 순간 놓치고, **서로를 탓하는 상황**이 만들어진다.
이 "남 탓의 재미"가 이 게임이 노리는 핵심 감정이다.

### 왜 추리가 어려운가 — 행동은 단서가 아니다

스캔당하거나 얻어맞은 NPC는 **도주 / 저항 / 순응** 중 하나로 반응한다.
그런데 반응 성향은 **무고한 시민도 절반이 비순응**(순응 0.5 / 도주 0.25 / 저항 0.25)으로 굴려진다.
즉 "도망가는 놈이 범인"이라는 직관은 대부분 **오검거**로 끝난다. 오직 스캔 정보와 몽타주 대조만이 수배범을 가린다.
추리 자체는 단순하게 두고, **검거 과정의 소동**에서 재미가 나오도록 설계했다.

## 한 라운드의 흐름

```
로비(준비) · 상점(아이템 구매) → 맵 선택 · 본부/현장 배치 → [ 제한시간 10분 ]
   몽타주 대조 → 스캔으로 이름 확인 → 무전 공유 → 추격 · 무력화 → 밧줄 연행 → 감옥 문 앞 판정
                              ↑ 돌발 이벤트 · 제보 전화 · 날씨가 계속 끼어든다
→ 목표 금액 달성 시 본부의 종료 버튼 활성화 → 정산(성과급 · 개인 칭호) → 다음 라운드
```

목표를 채워도 라운드가 자동으로 끝나지 않는다. **언제 끊을지도 팀의 판단**이다 — 더 벌지, 지금 접을지.
처음 하는 사람을 위한 **1인 전용 튜토리얼 맵**이 따로 있어, 이동부터 검거 판정까지 한 번 완주해 볼 수 있다.

## 주요 시스템

### 수사 — 몽타주로 좁히고 스캔으로 확정
- 수배 몽타주는 **머리스타일·머리색·피부색·수염·모자·안경 6축** 중 **공개된 축만** 그려진 픽셀 초상화다. 안 그려진 자리는 '없음'이 아니라 '미상'으로 읽히고, 라운드가 진행될수록 **화질이 흐려진다**(난이도 레버).
- 몽타주로 후보를 좁힌 뒤 **스캐너**로 이름·종족·세력을 확인해 수배 이름과 맞춘다. 스캔 1회당 **배터리 1** 소모, 충전은 **본부 충전기**에서만 가능해 현장↔본부 왕복 리듬을 만든다.
- **스캔당한 순간 대상이 반응한다.** 정보를 얻는 행위 자체가 리스크다 — 마구잡이 스캔은 용의자를 흩어 놓는다.
- 공개 축이 적을수록 몽타주에 걸리는 시민이 많아진다. 시민 이름은 통계 기반으로 생성돼 **닮은꼴이 흔하고**, 그래서 눈으로 고른 후보를 스캔으로 확정하는 절차가 필요하다.

### 검거 — 무력화 → 밧줄 → 감옥 문 앞 판정
- 깨어 있는 대상은 묶이지 않는다. **진압봉·테이저로 먼저 무력화**한 뒤 **밧줄**로 묶어 끌고 간다.
- 밧줄 1개당 1명, 인벤토리 5칸. 여러 명을 동시에 끌 수 있지만 **무게 합만큼 느려지고**, 같은 대상에 여러 명이 덧걸어 **줄다리기**도 가능하다(합류는 허용, 탈취는 차단).
- 끌려가는 몸은 **래그돌**이라 실제로 벽에 걸리고 문틀에 끼고, 멀어지면 줄이 끊긴다.
- 감옥 문 앞 **판정 버튼**을 눌러야 분류된다 — 수배범이면 수감·현상금, 무고한 시민이면 그 자리에서 석방.
- **현상금은 대상마다 다르다.** 라운드 시작에 맵별 범위(예: 6,000~12,000)에서 100원 단위로 추첨된다.
- 수배마다 **생사 조건**이 붙는다 — '생사 불문'은 시체로 인계하면 **감액**, '생포 필수'(약 35%)는 시체면 **0원**이다. 그래서 죽이지 않고 잡아 오는 것 자체가 실력이 된다.

### 돌발 이벤트 — 매 판 다른 소동
| 이벤트 | 내용 |
|---|---|
| 시스템 해킹 | 무전이 기계음으로 왜곡 + CCTV·미니맵·스캐너 정지 — **본부가 직접 복구해야 풀린다** |
| 동네 깡패 | 파이프를 들고 표적 한 명을 끝까지 쫓아와 때린다 |
| 공연음란범 | 속옷 차림으로 도심을 끝없이 질주 — 멈추는 구간이 없어 테이저가 필요하다 |
| 소매치기 | 시민 걸음으로 다가와 **손에 든 아이템을 채 간다** — 못 잡으면 그 물건은 영구 손실 |
| 범인 탈출 | 침입자가 배전반을 해킹해 수감자 전원 탈출 — 다시 잡아 와야 한다 |
| 추격 폭탄 | 가장 가까운 현장 인원을 쫓아온다. 해체 불가 — 도망치는 수밖에 |
| 플레이어 납치 | **혼자 다니는** 현장 인원을 맨홀로 끌고 간다 — 동료가 떼어내면 구조 |
| 세력 소탕 | 수감자의 세력이 복수대를 보내 한 명을 집요하게 노린다 |
| 밀수 운반책 | 초중량 화물 — **혼자서는 끌 수 없어 둘 이상이 덧걸어야** 이송된다 |

여기에 **라운드 날씨**(번개·안개·눈 — 맵별 확률표로 추첨), **UFO 빔**, 상시 흐르는 **도로 교통**이 그 판의 조건으로 얹힌다.
차에 치이면 다운 유예 없이 **즉사**라, 도로는 배경이 아니라 위협이다.

### 경제 — 벌어서 사고, 사서 더 잡는다
정산한 돈으로 **상점**에서 다음 라운드 장비를 산다. 진열대는 **고정 5칸 + 랜덤 3칸**으로 매 라운드 재추첨된다.

| 품목 | 가격 | 비고 |
|---|---|---|
| 힐팩 | 2,000 | 소모품 |
| 구역 스캐너 | 3,000 | 반경 20m에 수배범이 있는지 여부만 링으로 표시 (쿨타임 60초) |
| 거대 뿅망치 | 3,000 | 평타는 체력 1, 낮은 확률로 즉사 — 개그 무기 |
| 휴대용 미니맵 | 3,000 | 현장에서도 지도를 본다 |
| 부활 키트 | 5,000 | 소모품 |
| 유치장 사이렌 버튼 | 5,000 | 설치형 — 본부에서 탈옥을 원격 제지 |
| 테이저 건 | 7,500 | 어떤 상태의 NPC든 3초 무력화 (동료를 맞히면 5초 기절) |
| 홈런 진압봉 | 10,000 | 데미지 0 — 차지해서 날려 버린다 |
| 신호 해석기 | 10,000 | 설치형 — 텍스트 브로드캐스트, **해킹 중에도 통한다** |

## 코드 구조

전역 매니저 접근을 **`App` 파사드 하나**로 통일하고, 기능은 **도메인 폴더**로 나눈다.
구조 규칙은 [docs/architecture.md](docs/architecture.md)에 R1~R8로 명문화되어 있고, PR 리뷰가 이 문서를 기준으로 검사한다.

```
사용하는 쪽 컴포넌트 ──(App.그룹.매니저 로만 접근)──▶ App (전역 파사드)
                                                       ▲
매니저 ──(베이스 상속만 하면 Awake에서 자동 등록)──────┘
```

- `App.Net` — 세션 · 인증 · Vivox   |   `App.Game` — 라운드 · NPC · 판정 · 이벤트 · 감옥 · 연출
- `App.UI` — HUD 표시 컴포넌트   |   `App.SceneFlow` — 씬 전환   |   `App.Sound` — 사운드
- 매니저 검색(`FindFirstObjectByType`)과 신규 싱글톤 금지, 씬 전환은 `App.LoadScene` 단일 경로(세션 중이면 NGO 씬 동기화로 자동 분기)

```
Assets/Scripts/
├── Core/        App 파사드 · 매니저 등록 · 씬 로드
├── Network/     세션 · 인증 · Vivox · teardown
├── Round/       라운드 진행 · 제한시간 · 할당량표 · 정산
├── NPC/         FSM · NavMesh · 반응 · 외형/몽타주 · 스폰
├── Player/      이동 · 시야 · 인벤토리 · HP/다운 · 연행 · 감정표현
├── HQ/          CCTV · 미니맵 · 수배 리스트 · 제보 전화 · 원격 문 · 유치장 경보
├── Item/        스캐너 · 밧줄 · 진압봉 · 배터리 · 상점 아이템
├── Events/      돌발 이벤트 9종 · 날씨 · UFO
├── Economy/     자금 · 상점 진열/배달 · 구매 이력
├── Interaction/ 조준 상호작용(E) · 검거 판정 · 유치장 인계
├── Traffic/     도로 교통      ├── Tutorial/  1인 튜토리얼
├── Common/      래그돌 등 공용 부품
└── UI · Audio · Vfx · Data · Save · Localization · Scene
```

C# 코딩 컨벤션: `m_`(인스턴스 멤버) · `s_`(static) · `k_`(const) · `I`(인터페이스) · `On`(이벤트), 프로퍼티/메서드는 PascalCase.

## 담당 파트

이 저장소는 4인 팀 프로젝트이며, 본인(**김진아**)은 **네트워크 기반과 본부(관제) 시스템**을 맡았다. (커밋 683건)
